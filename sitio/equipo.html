Godot 4.7

GDScript, escritorio con Forward+ y web con un solo hilo. Una base de código para Windows y navegador.GDScript, desktop with Forward+ and single-threaded web. One code base for Windows and the browser.

Tres capasThree layers

Datos en JSON, simulación pura y la vista. La simulación se prueba sola, con más de 670 pruebas automáticas y una prueba completa del juego en red.JSON data, a pure simulation and the view. The simulation is tested on its own, with over 670 automated tests and a full test of online play.
